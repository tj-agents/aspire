# aspire

Aspire runtime inspection and debugging standards for coding agents.

This is a personal project, explicitly adopting the Personal profile. Tommy has declared all
`tj-agents` source repositories personal projects.

Published as `aspire@tj-agents` from the shared `tj-agents` marketplace.

## Skills

- Utilities: `aspire:debug`.

## Authoring and verification

```powershell
pwsh .agents/sync-generated.ps1
pwsh .agents/sync-generated.ps1 -Check
```

The layout, the vendored generator and CI come from [Template](https://github.com/tj-agents/template).
